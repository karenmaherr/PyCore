# PyCore

A personal collection of Python practice projects covering **Python Fundamentals**, **Machine Learning**, **Deep Learning**, and **Agentic AI** practice. This repo serves as a playground for applying concepts learned through coursework and self-study.

##  About

PyCore is where I build, break, and rebuild things while learning ML/DL/Agentic AI. Each project is self-contained and focused on a specific concept, technique, or tool.

##  Topics Covered

- **Machine Learning**: model building & evaluation, etc
- **Deep Learning**: neural networks, etc
- **Agentic AI**: building and experimenting with AI agents while learning

##  Tech Stack

- Python
- Common ML/DL libraries (NumPy, Pandas, Scikit-learn, etc.)
- Jupyter Notebooks for experimentation

##  Getting Started

Each project folder includes its own code and (where relevant) a brief explanation of what it does and what was learned.

##  Purpose

This repo is a living log of my learning journey in AI/ML — not a production codebase. Expect experiments, iterations, and continuous updates as I grow my skills.
